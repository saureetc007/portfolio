1. EXECUTIVE SUMMARY & DESIGN PHILOSOPHY
================================================================================
This repository houses the personal engineering portfolio of Saureet Chakrabarti.
The application departs from standard static web portfolios by providing an
ultra-immersive, cinematic dark streaming aesthetic directly inspired by Netflix
and high-performance developer tools.

Key Themes:
- Streaming-Grade Dark Visual Identity: Solid black (#000000), deep Netflix charcoal
  (#141414), secondary card surface (#181818), and authentic Netflix Crimson Red
  (#E50914) with dimensional dark red accents (#B20710).
- Extreme Motion Design: Multi-axis 3D perspective card physics, momentum-based
  swiping, high-velocity character deciphering, liquid cursor rings, and smooth
  layered transitions.
- Interactive Proof-of-Skill: Live in-browser runnable code editor with simulated
  Python and TypeScript engine runtimes, real-time tensor normalization output,
  and interactive terminal CLI.
- 3D Interactive Cosmos: Three.js WebGL scene with 850 interactive nodes representing
  technologies connected via dynamic neural pathways.
- Accessibility & Performance: Strict compliance with prefers-reduced-motion,
  Retina devicePixelRatio canvas scaling, zero-blur GPU transforms, and WCAG AA contrast.

7. SECURITY, SANITIZATION & PERFORMANCE OPTIMIZATIONS
================================================================================
Security:
- Strict HTML entity encoding in contact validation prevents script injection (XSS).
- Anti-spam honeypot field catches automated bots with decoy 200 responses.
- Environment variables (RESEND_API_KEY) remain strictly server-side inside api/.

Performance & Bundle Engineering:
- Code Splitting in vite.config.ts:
  * 'three': Three.js library isolated into its own 532KB chunk.
  * 'motion': Motion v14 isolated into a 126KB chunk.
  * 'react': React core isolated into a 12KB chunk.
  * 'index': Main application entry bundle reduced to 553KB.
- Retina 4K Display Optimization:
  * All canvas elements detect window.devicePixelRatio and scale buffer dimensions.
  * CSS image-rendering: -webkit-optimize-contrast applied to media elements.
- Zero Unnecessary Repaints:
  * Heavy visual effects use GPU-accelerated CSS properties (transform, opacity).
  * Inactive background tabs pause animation frames to minimize CPU load.
